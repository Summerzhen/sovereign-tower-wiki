## 快速回答

最佳开局策略是将前几个周期作为侦察路线来玩。接受你实际能派人的任务，保持护甲完好，记录派系变化，并利用圆桌了解哪些骑士适合解决哪类问题，再去追求完美结局。

先从[完整流程攻略](/guide/sovereign-tower-walkthrough)开始，然后每当出现特定任务时使用[任务查找器](/quests)。

## 开局优先顺序

| 优先事项 | 重要性 |
|---|---|
| 保持早期骑士存活 | 死亡或离队会在路线展开前缩小你的圆桌阵容 |
| 记录觐见选择 | 朝会决策会生成任务、费用、派系变化和路线标记 |
| 优先按属性匹配任务 | 偏好很重要，但可见要求是最安全的首轮筛选条件 |
| 维持派系平衡 | 极端的派系波动可能会在你理解之前就关闭后续选择 |
| 谨慎解锁辅助房间 | 锻造、内务、地图和炼金辅助可以避免不必要的失败 |

## 第一周期清单

1. 在接受太多任务之前，先记下每个觐见请求。
2. 注意可见的费用、派系和路线警告文本。
3. 先分配最安全的任务，而非最耀眼的任务。
4. 避免派遣受损或属性不匹配的骑士执行危险任务。
5. 在回溯或继续之前记录结果。

## 最佳早期任务分配

| 任务类型 | 更安全的开局选择 |
|---|---|
| 动物、森林或轻松差事 | 测试安吉莉卡式的敏捷、运气和动物亲和特质 |
| 公开朝会或贵族施压 | 仅在骑士性格不会破坏场景时使用高魅力 |
| 战斗、狩猎或怪物问题 | 检查力量、敏捷、护甲，以及骑士是否喜欢危险工作 |
| 调查或线索路线 | 优先考虑智慧和运气，然后记录隐藏特质是否有影响 |
| 奇异或超自然事件 | 不要假设战斗能解决问题；检查魔法、智慧和路线警告 |

## 早期应避免的行为

| 错误 | 更好的开局习惯 |
|---|---|
| 接受所有请愿 | 只接受你的阵容和资金能支撑的任务 |
| 在看到任务风险前花光所有钱 | 保留足够资金用于修理、装备和紧急公共需求 |
| 不做记录就使用回溯 | 先将失败结果保存为路线知识 |
| 立即追逐招募传闻 | 在改变路线前确认场景、触发条件和路线状态 |
| 围绕一个喜爱的骑士构建阵容 | 保持阵容灵活性以应对不同的属性检定 |

## 常见问题

### 是否有一条最佳开局路线？

目前没有。将最佳开局视为一个可靠的流程：保护阵容、保持资金灵活、了解任务要求，并避免不可逆的假设。

### 早期应该使用恶魔之力吗？

可以用来测试，但先记录原始失败结果。回溯的价值在于你携带前进的信息。

### 是否应该尽快招募所有人？

仅限路线支持的情况下。招募可能与阵容容量、忠诚度、派系压力和任务获取产生交互，因此在强行招募前先确认代价。
