## 快速回答

主权塔任务结果不仅仅是通过或失败的信息。它们可以改变奖励、护甲损坏、好感度、阵营状态、招募线索、后续任务以及结局路线。每当结果出乎意料时，请记录骑士、属性、特质、装备和路线状态。

使用[任务查询器](/quests)打开任务记录，然后将本页面与[意外结果](/guide/sovereign-tower-unexpected-outcomes)进行对比，以了解隐藏或异常的结果。

## 结果类型

| 结果 | 通常含义 |
|---|---|
| 大成功 | 骑士超越了要求或与任务异常契合 |
| 成功 | 任务完成，未造成重大路线损害 |
| 失败 | 任务未满足某项要求、特质匹配或路线条件 |
| 大失败 | 结果造成了严重伤害、死亡风险、阵营损害或路线丢失 |
| 意外结果 | 隐藏特质、奇怪选择或路线标记改变了预期结果 |

## 每次任务后需记录的内容

| 字段 | 重要性 |
|---|---|
| 指派骑士 | 便于比较属性、特质、忠诚度和偏好 |
| 所需属性 | 显示可见要求是否能解释结果 |
| 装备/支援 | 装备、药水、餐食和附属支援可能改变阈值 |
| 护甲与伤害 | 存活的成功仍可能造成未来的死亡风险 |
| 阵营变化 | 某些结果之所以重要，是因为它们改变了政治状态 |
| 后续事件 | 奖励、觐见、招募线索和路线锁定往往在之后出现 |

## 结果诊断

| 如果你看到了这个 | 首先检查这个 |
|---|---|
| 成功但奖励低 | 缺少特质匹配、好感度低或未达到暴击阈值 |
| 属性好却失败 | 不喜欢的任务类型、隐藏特质冲突、忠诚度问题或路线状态错误 |
| 大失败 | 护甲、危险警告、缺少关键属性或被迫接受糟糕任务 |
| 意外结果 | 隐藏特质、特殊对话、前置任务或回溯知识 |
| 后续事件消失 | 不同的觐见选择、阵营数值、招募状态或时机 |

## 回溯测试方法

1. 在笔记中保存原始结果。
2. 更改变一个变量：骑士、装备、对话或任务顺序。
3. 再次运行任务并仅比较该变量。
4. 当结果重复出现时，将其添加到任务记录中。

## 常见问题

### 意外结果总是好的吗？

不是。意外结果可能是隐藏的好处、奇怪的并发症或路线警告。在决定是否回溯之前，将其视为信息来处理。

### 普通成功也可能是不好的吗？

是的。任务可能成功的同时损坏护甲、降低好感度、花费过多金钱或将阵营推向错误方向。

### 每个结果都应该有自己的页面吗？

不需要。首先将结果保留在任务数据库中。仅当玩家搜索该特定结果或路线影响较大时，才拆分单独页面。
