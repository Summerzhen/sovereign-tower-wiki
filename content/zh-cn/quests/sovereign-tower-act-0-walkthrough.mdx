## 快速回答

对于 Act 0，重点是保持一个干净的开局状态。官方试玩报道确认 Act 0 为开局/序章层，因此请记录首次觐见顺序、可用骑士、可见任务需求，以及当前存档中显示为持久化的任何选择。

## Act 0 概览

| 路线节点 | 需要追踪的内容 |
|---|---|
| 开局状态 | 初始阵容、首次觐见序列、教程提示和早期路线锁定 |
| 需求备注 | 仅使用当前存档中可见的需求文本；Steam 确认官方骑士属性为力量、敏捷、魅力、魔法和智慧 |
| 分配逻辑 | 优先选择符合可见需求的骑士，再考虑偏好或剧情风格 |

| 主要产出 | 确认过渡到早期循环，并附带已知阵容和路线备注 |

## 分步指南

1. 在接受第一个任务或做出觐见决定之前，为 Act 0 创建一个时间线。
2. 列出每个可用骑士以及任何可见的属性、特质、忠诚度或偏好线索。
3. 对于每个任务，记下界面中显示的精确需求。
4. 首先按需求匹配度分配骑士，然后记录偏好或特质文本是否改变了结果。
5. 将教程失败的备注与永久路线后果分开保存。
6. 在 Act 0 结束时，总结阵容、未解决的任务线索，以及任何可能影响 Act 1 的选择。

## 常见问题

### Act 0 的选择会封锁后续路线吗？

在当前存档中测试之前，请将其视为可能。开局选择应仔细追踪，因为后续的招募、忠诚度和任务可用性可能取决于早期状态。

### Act 0 应该分配谁？

分配符合可见任务需求的骑士。当安吉丽卡和格温丹的属性或特质匹配时，她们是有用的早期对比候选，但最终应由界面需求来决定。

### Act 0 和试玩版一样吗？

不一定。除非当前存档确认它们共享相同的任务、标记和进度，否则请将 Act 0 的备注与试玩版的备注分开保存。
