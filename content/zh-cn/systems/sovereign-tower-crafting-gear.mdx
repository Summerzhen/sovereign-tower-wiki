## 快速回答

制作和装备应当为好的派遣提供支持，而非拯救糟糕的派遣。先选择正确的骑士，然后在高风险任务前使用锻造物品、修理、药水或附属建筑支持来弥补小的弱点。

将本页与[铁匠指南](/systems/sovereign-tower-blacksmith)、[附属建筑](/systems/sovereign-tower-annexes-buildings)和[任务查找器](/quests)配合使用。

## 装备规划表

| 装备目标 | 使用时机 |
|---|---|
| 弥补某项缺失属性 | 骑士在其他方面与任务高度匹配 |
| 保护护甲 | 任务有死亡或受伤风险，且骑士必须存活 |
| 推动关键成功 | 奖励或路线后果值得投入资源 |
| 支持调查 | 智力或运气接近但还不够 |
| 支持特殊路线 | 魔法、药水或超自然支持可能有用 |

## 制作优先级

| 路线问题 | 首要装备问题 |
|---|---|
| 战斗路线 | 护甲是否已修理，骑士是否满足力量/敏捷需求？ |
| 外交路线 | 魅力是否足够，骑士的性格是否会带来风险？ |
| 调查路线 | 装备或药水能否支持智力/运气而不削弱生存能力？ |
| 魔法路线 | 路线要求的是魔法、智力还是两者都需要？ |
| 龙骑士压力 | 哪四位骑士必须存活、装备齐全且可用？ |

## 不要过度使用装备

| 坏习惯 | 更安全的习惯 |
|---|---|
| 派错骑士并配以昂贵装备 | 先选对骑士，再提升容错空间 |
| 在一个任务上耗尽所有资源 | 留钱用于修理、觐见和附属建筑需求 |
| 忽视好感度与忠诚度 | 被强化的骑士仍可能产生糟糕的路线结果 |
| 将每件物品视为已确认 | 在发布前记录物品效果、属性变化和任务结果 |

## 常见问题

### 每个任务前都需要制作吗？

不需要。仅在高风险、有截止日期、路线锁定或有死亡风险的任务前制作。日常差事不应消耗你的资源。

### 装备能改变任务结果吗？

可以，尤其是当骑士接近所需属性阈值时。在将物品视为已确认的解决方案之前，请记录使用前后的结果。

### 护甲修理比属性装备更重要吗？

对于危险任务，通常是。如果骑士死亡或返回时受损过重无法应对下一个必要路线，属性加成就毫无意义。
