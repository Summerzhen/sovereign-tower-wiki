## 快速回答

根据当前路线实际产生的问题来建造附属建筑。如果骑士受到伤害，优先建造锻造和修理支援设施。如果出现魔法或异常任务，追踪炼金和超自然支援。如果招募因容量或人员访问受限而受阻，记录是哪栋建筑开启了该位置。

配合[地图指南](/systems/sovereign-tower-map)、[铁匠指南](/systems/sovereign-tower-blacksmith)和[任务数据库](/quests)使用本页面。

## 建筑优先级表

| 附属建筑/建筑 | 主要价值 | 升级前需追踪 |
|---|---|---|
| 执政厅 | 传闻、骑士秘密、路线情报 | 它揭示了哪个骑士线索以及是否影响派遣选择 |
| 锻造坊/铁匠铺 | 装备、护甲修理、物理任务支援 | 护甲状态、修理上限、物品加成和避免的失败任务 |
| 巫师/炼金室 | 药水、魔法支援、异常路线准备 | 魔法需求、药水效果、成本和路线后果 |
| 地图/画廊 | 区域访问、受损地点追踪、外部请求 | 地点状态、税收价值、修理成本和可用路线 |
| 陵墓 | 回溯和路线测试 | 回溯后发生了什么变化以及知识是否创造了新选择 |

## 如何决定下一栋建筑

| 当前问题 | 优先建造或使用 |
|---|---|
| 骑士死亡或返回时受损 | 锻造坊、护甲修理和更安全的任务匹配 |
| 无法应对魔法或异常任务 | 巫师/炼金支援和魔法专精骑士 |
| 缺少招募线索 | 执政厅和骑士档案追踪 |
| 区域受损或收入不稳定 | 地图/画廊修理循环 |
| 需要测试高风险分支 | 陵墓和书面路线记录 |

## 附属建筑数据格式

每个建筑页面最终应使用相同的数据库式字段：

| 字段 | 需记录的示例数据 |
|---|---|
| 解锁条件 | 剧情节点、资源消耗、阵营状态、路线选择或招募数量 |
| 功能 | 修理、制作、揭示线索、解锁位置、开启地图路线或修改觐见 |
| 最佳时机 | 早期循环、龙骑士之前、第二章之前或特定路线 |
| 相关系统 | 骑士、任务、餐食、结局、魔王之力或阵营 |
| 可信度 | 已确认、已重复、已报告或仍未知 |

## 常见问题

### 附属建筑只是升级吗？

不是。附属建筑影响路线安全，因为它们可以揭示信息、修理损伤、支援属性、解锁宫廷职位，并改变骑士在任务前的准备程度。

### 我应该先建造哪个附属建筑？

优先建造能解决你实际遇到的失败问题的附属建筑。对于大多数高风险路线，修理和信息比盲目扩张更有用。

### 附属建筑会影响招募吗？

可能会。在将其作为确认的招募条件之前，追踪新附属建筑是否开启了宫廷职位、人员角色、觐见或路线场景。
