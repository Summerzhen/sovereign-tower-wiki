## Quick Answer

For the Sovereign Tower demo, play one careful baseline route before optimizing. Official announcements confirm the demo covers Act 0 and Act 1 content, so record every visible quest requirement and keep separate notes for confirmed text versus assumptions you still need to test.

## Step-by-Step

1. Start the demo with a fresh note page for quest names, audience order, available knights, and any tutorial warnings.
2. When a quest appears, copy the visible requirement before choosing a knight.
3. Compare the requirement against your roster instead of assuming the easiest-looking quest is harmless.
4. Use low-risk tutorial assignments to learn how success, failure, loyalty, and trait text are reported.
5. Mark every unclear route flag as pending confirmation, especially references to servants, factions, hidden traits, or future regions.
6. After clearing the demo, review which notes are firm enough to become quest records and which need a second pass.

## FAQ

### Is this a full demo solution?

It is a cautious route page for building reliable notes. Exact demo-only quest solutions should be added after the current demo build is replayed and the visible requirement text is confirmed.

### Should I optimize the first demo run?

Not immediately. A baseline run is more useful because it shows what the game explains, which choices are reversible, and which requirements are easy to miss.

### Are the listed stats confirmed?

Yes for the official Knight stat list: Strength, Agility, Charisma, Magic, and Wit. Treat any other demo-specific check as in-game behavior that still needs in-game comparison.
