## Sovereign Tower True Ending: What Players Need to Track

The True Ending should be treated as a route ledger rather than a single checklist until every trigger is repeatable in-game. Record the choices, quest outcomes, affinity state, recruitment state, and ending result for each run.

## Does Demon Power Lock the True Ending?

Do not treat Demon Power or a rewind as an automatic lockout without a confirmed test. Log when Demon Power was used, which cycle was revisited, what knowledge carried over, and whether the final ending changed.

## Can You Get the True Ending After Resetting?

Compare a reset run with the original run using the same key choices. Track which flags, dialogue options, knight recruitment states, and quest outcomes persist. A reset result should be documented separately from a time-rewind result.

## New Game Plus and the True Ending

For New Game Plus or Try Again, record:

- carried-over knowledge or dialogue
- earlier knight recruitment opportunities
- changed quest availability or outcomes
- affinity and romance state
- final choices and ending text

Until these fields are confirmed across multiple runs, label them as route-dependent rather than guaranteed requirements.
