## 빠른 답변

동맹 루트에서는 모든 동맹 제안을 출처, 세력 비용, 배정한 기사, 후속 효과와 함께 기록하세요. 카리스마와 재치는 유용한 계획 범주지만, 정확한 임계값은 게임이 보여주기 전까지 미확정으로 남겨야 합니다.

## 동맹 개요

| 루트 지점 | 작업 계획 |
|---|---|
| 주요 목표 | 이후 루트에 필요한 세력 안정성을 보존하면서 동맹을 맺거나 거절한다 |
| 계획용 스탯 | 카리스마 우선, 재치 다음, 운은 이벤트 문구가 불확실성을 암시할 때만 |
| 추천 기준점 | Gwendan, Angelica, Brunhilda는 사용 가능할 때 비교 기준으로 유용하다 |
| 최적 특성 | 궁정 지향, 외교형, 안정적인 충성도 특성 |
| 주요 위험 | 한 동맹이 외부 세력을 만족시키는 동시에 내부 세력을 화나게 할 수 있다 |

## 단계 / 루트 적합성

1. 각 동맹 제안을 소개하는 알현, 퀘스트, 지역 이벤트를 기록합니다.
2. 결정하기 전에 상인, 신비주의자, 학자, 귀족, 민중, 재정의 현재 입장을 적습니다.
3. 검증되지 않은 스탯 표가 임계값을 암시해서가 아니라, 표시 문구가 적합성을 뒷받침하기 때문에 기사를 배정합니다.
4. 되감기로 깨끗한 테스트가 가능하다면 외교형 선택을 최소 하나의 대안과 비교합니다.
5. 동맹 결과를 이후 반란, 세력, 로맨스, 전체 캠페인 루트 메모와 연결합니다.
6. 지원, 압박 완화, 후속 알현이 반복될 때만 동맹을 확인됨으로 표시합니다.

## 확인할 사항

| 확인할 주장 | 검증 메모 |
|---|---|
| 동맹 출처 | 제안이 퀘스트, 알현 청원, 지역 이벤트, 막 전환 중 어디서 오는지 확인 |
| 외교 관문 | 가능한 경우 카리스마와 재치 임시값을 정확한 표시 요구사항으로 교체 |
| 기사 이미지 | 충성도, 대중 평판, 숨은 특성이 협상 결과를 바꾸는지 테스트 |
| 세력 비용 | 동맹 후 누가 승인을 얻고 누가 잃는지 추적 |
| 이후 결과 | 동맹이 반란 압박, 영입, 로맨스, 엔딩을 바꾸는지 확인 |

## FAQ

### 모든 동맹을 받아들여야 하나요?

아니요. 동맹은 유용할 수 있지만, 각 동맹은 세력 비용, 루트 우선순위, 이후 정치적 압박을 기준으로 판단해야 합니다.

### 카리스마 판정은 확인되었나요?

이 페이지에서는 정확한 임계값으로 확인하지 않습니다. 게임이 요구사항을 표시하거나 반복 테스트가 확인하기 전까지 카리스마를 가능성 높은 외교 범주로 다루세요.

### 어떤 기사를 먼저 테스트해야 하나요?

가능하다면 Gwendan, Angelica, Brunhilda처럼 궁정 지향 기사부터 시작하고, 그 결과를 덜 맞는 선택과 비교하세요.

### 동맹이 루트를 잠글 수 있나요?

가능성은 있지만, 같은 동맹이 여러 통제된 실행에서 같은 이후 선택지를 막기 전까지는 잠금으로 확정하지 마세요.
