## 빠른 답변

동맹 루트에서는 모든 동맹 제안을 출처, 세력 비용, 배정 기사, 후속 효과와 함께 문서화하세요. Charisma와 Wit은 유용한 계획 범주지만, 정확한 임계값은 게임이 노출하기 전까지 미확정으로 두는 것이 안전합니다.

## 동맹 개요

| 루트 포인트 | 작업 계획 |
|---|---|
| 주요 목표 | 이후 루트에 필요한 세력 안정성을 유지하면서 동맹을 체결하거나 거절 |
| 계획용 능력치 | Charisma 우선, Wit 보조; UI가 능력치를 표시하지 않으면 불확실성을 따로 기록 |
| 추천 기준점 | 가능할 때 Gwendan, Angelica, Brunhilda를 비교 대상으로 사용 |
| 좋은 특성 | 궁정형, 외교형, 안정적인 충성도 특성 |
| 주요 위험 | 한 동맹이 외부 세력을 만족시키는 동시에 내부 세력을 화나게 할 수 있음 |

## 단계 / 루트 적합도

1. 각 동맹 제안을 소개하는 알현, 퀘스트, 지역 이벤트를 기록합니다.
2. 결정 전에 Merchants, Mystics, Scholars, Nobles, the People, Treasury의 현재 상태를 적습니다.
3. 현재 빌드 계획표가 임계값을 암시해서가 아니라, 표시 텍스트가 적합성을 뒷받침할 때 기사를 배정합니다.
4. 되감기로 깨끗한 테스트가 가능하다면 외교형 선택을 최소 하나의 대안과 비교합니다.
5. 동맹 결과를 이후 Rebellion, Factions, 로맨스, Full Campaign 루트 메모와 연결합니다.
6. 지원, 압박 완화, 후속 알현이 반복될 때만 동맹을 확인됨으로 표시합니다.

## 현재 빌드 확인 사항

| 확인할 주장 | 검증 메모 |
|---|---|
| 동맹 출처 | 제안이 퀘스트, 알현 청원, 지역 이벤트, 액트 전환 중 어디서 오는지 확인 |
| 외교 게이트 | 가능하면 정확히 보이는 Charisma와 Wit 요구 조건을 기록 |
| 기사 이미지 | 충성도, 공적 평판, 숨은 특성이 협상 결과를 바꾸는지 테스트 |
| 세력 비용 | 동맹 뒤 누가 승인도를 얻고 누가 잃는지 추적 |
| 이후 결과 | 동맹이 반란 압박, 영입, 로맨스, 엔딩을 바꾸는지 확인 |

## FAQ

### 모든 동맹을 받아들여야 하나요?

아니요. 동맹은 유용할 수 있지만 각 동맹은 세력 비용, 루트 우선순위, 이후 정치 압박과 비교해서 판단해야 합니다.

### Charisma 체크는 확인되었나요?

이 페이지에서는 정확한 임계값으로 확정하지 않습니다. 게임이 요구 조건을 표시하거나 반복 테스트가 확인하기 전까지 Charisma를 유력한 외교 범주로 다루세요.

### 어떤 기사를 먼저 테스트해야 하나요?

가능할 때 Gwendan, Angelica, Brunhilda처럼 궁정에 맞는 기사부터 시작하고, 더 낮은 적합도의 선택과 결과를 비교하세요.

### 동맹이 루트를 잠글 수 있나요?

가능성은 있지만, 같은 동맹이 여러 통제 플레이에서 같은 이후 선택지를 막기 전까지 잠금으로 확정하지 마세요.
