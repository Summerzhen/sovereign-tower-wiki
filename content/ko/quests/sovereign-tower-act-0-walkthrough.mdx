## 빠른 답변

Act 0에서는 깨끗한 시작 상태를 보존하는 데 집중하세요. 첫 알현 순서, 사용 가능한 기사, 보이는 퀘스트 요구 조건, 모집과 충성도 또는 이후 루트 접근에 영향을 줄 것 같은 선택을 모두 기록하세요.

## Act 0 개요

| 루트 지점 | 추적할 것 |
|---|---|
| 시작 상태 | 시작 기사 명단, 첫 알현 순서, 튜토리얼 안내, 초반 루트 잠금 |
| 요구 조건 메모 | 정확한 값이 확인될 때까지 재치, 매력, 민첩을 초반 가능성 높은 판정으로 다루기 |
| 배정 논리 | 선호도나 이야기 분위기보다 보이는 요구 조건에 맞는 기사를 먼저 고르기 |
| 되감기 사용 | 진짜 잠금과 수정 가능한 선택을 분리하기 |
| 주요 결과 | 알려진 기사 명단과 루트 메모를 가진 상태로 초반 사이클에 검증된 전환 만들기 |

## 단계별 진행

1. 첫 퀘스트나 알현 결정을 수락하기 전에 Act 0 타임라인을 만드세요.
2. 사용 가능한 모든 기사와 보이는 능력치, 특성, 충성도, 선호 단서를 적으세요.
3. 각 퀘스트마다 인터페이스에 표시된 정확한 요구 조건을 기록하세요.
4. 먼저 요구 조건 적합도로 기사를 배정한 뒤, 선호도나 특성 문구가 결과를 바꾸는지 기록하세요.
5. 튜토리얼 실패 메모는 영구적인 루트 결과와 따로 보관하세요.
6. Act 0이 끝나면 기사 명단, 미해결 퀘스트 단서, Act 1에 영향을 줄 수 있는 선택을 요약하세요.

## 확인할 사항

| 확인할 주장 | 검증 메모 |
|---|---|
| 초반 알현 순서 | 순서가 고정인지, 초기 결정에 영향을 받는지 확인하기 |
| 능력치 조건 | 재치, 매력, 민첩 임시 메모를 보이는 요구 조건 문구로 교체하기 |
| 초반 모집 | Act 0에서 어떤 기사를 놓치거나 늦추거나 상태가 바뀔 수 있는지 기록하기 |
| 되감기 한계 | 장기 비용 없이 수정 가능한 실패 선택이 무엇인지 확인하기 |
| 루트 전환 | 초반 사이클로 넘어가는 요소를 기록하기: 충성도, 부상, 플래그, 보상, 퀘스트 이용 가능 여부 |

## FAQ

### Act 0 선택이 이후 루트를 막을 수 있나요?

테스트되기 전까지는 가능하다고 다루세요. 이후 모집, 충성도, 퀘스트 이용 가능 여부가 초반 상태에 의존할 수 있으므로 시작 선택은 신중하게 추적해야 합니다.

### Act 0에서는 누구를 배정해야 하나요?

보이는 퀘스트 요구 조건에 맞는 기사를 배정하세요. Angelica와 Gwendan은 능력치나 특성이 맞을 때 초반 비교 후보로 유용하지만, 최종 판단은 UI 요구 조건이 해야 합니다.

### Act 0은 데모와 같은가요?

반드시 그렇지는 않습니다. 현재 빌드가 같은 퀘스트, 플래그, 진행을 공유한다고 확인해 주지 않는 한 Act 0 메모와 데모 메모는 분리하세요.
