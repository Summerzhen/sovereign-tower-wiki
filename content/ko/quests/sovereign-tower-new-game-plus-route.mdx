## 빠른 답변

New Game Plus 루트 조언을 사용하기 전에, 플레이 중인 현재 빌드에 New Game Plus가 존재하는지 확인하세요. 존재한다면 이월 요소, 변경된 퀘스트 요구 조건, 기사 명단 변화, 숨겨진 지식을 기본 캠페인 루트와 별도로 문서화하세요.

## New Game Plus 개요

| 루트 지점 | 확인할 것 |
|---|---|
| 모드 상태 | 현재 빌드에 New Game Plus가 있고 접근 가능한지 확인하기 |
| 이월 요소 | 지식, 기사 명단, 특성, 해금, 자원, 루트 플래그 확인하기 |
| 능력치 메모 | 행운, 재치, 마법은 임시 계획 범주로만 다루기 |
| 비교 루트 | 바뀐 모든 퀘스트를 기본 캠페인 버전에 연결하기 |
| 주요 위험 | 빌드 의존 동작을 보편적인 것처럼 게시하는 것 |

## 단계별 진행

1. 필요한 엔딩 상태를 완료하거나 불러온 뒤 New Game Plus 옵션이 실제로 제공되는지 확인하세요.
2. 새 루트를 시작하고 퀘스트를 받기 전에 정확히 무엇이 이월되는지 기록하세요.
3. 시작 알현 순서를 Act 0 및 초반 사이클 메모와 비교하세요.
4. 이전에 숨겨졌던 특성, 요구 조건, 루트 힌트가 이제 보이는지 확인하세요.
5. 변경된 퀘스트마다 기본 버전, NG+ 버전, 실제 영향을 기록하세요.
6. 여러 플레이가 같은 해금과 루트 차이를 확인할 때까지 이 페이지를 신중한 상태로 유지하세요.

## 확인할 사항

| 확인할 주장 | 검증 메모 |
|---|---|
| 해금 조건 | 모드를 여는 엔딩, 저장 상태, 메뉴 옵션을 기록하기 |
| 기사 명단 이월 | 기사, 충성도, 부상, 모집 상태가 유지되는지 확인하기 |
| 지식 이월 | 요구 조건, 특성, 루트 메모가 더 일찍 보이는지 확인하기 |
| 퀘스트 변화 | 보상, 능력치 판정, 위험, 예상 밖의 결과를 일반 루트와 비교하기 |
| 빌드 의존성 | 동작이 다를 때마다 게임 버전이나 데모 상태를 적기 |

## FAQ

### New Game Plus는 확정인가요?

현재 빌드가 모드와 해금 동작을 확인해 줄 때까지 이 페이지는 검증 루트로 다뤄야 합니다.

### 무엇을 먼저 비교해야 하나요?

시작 상태, 사용 가능한 기사, 보이는 요구 조건, 루트 플래그를 비교하세요. 첫 NG+ 테스트에서는 보상 최적화보다 이런 차이가 더 중요합니다.

### New Game Plus가 모집을 바꿀 수 있나요?

그럴 수도 있지만 단정하지 마세요. 확정적인 주장을 하기 전에 Brunhilda 관련 플래그를 포함한 모집 루트를 일반 캠페인 기준선과 비교해 추적하세요.
