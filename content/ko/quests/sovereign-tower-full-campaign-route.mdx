## 빠른 답변

전체 캠페인 루트는 하나의 고정 walkthrough가 아니라 루트 장부로 관리하는 것이 안전합니다. 엔딩이나 하드락을 확정하기 전에 각 액트, 주요 세력 변화, 영입 가능한 기사 분기, 하인 또는 부속 시설 해금, 로맨스 플래그를 모두 기록하세요.

## 캠페인 개요

| 루트 포인트 | 작업 계획 |
|---|---|
| 주요 목표 | 액트, 지역 허브, 영입 분기, 엔딩 체크를 잇는 완전한 지도 만들기 |
| 계획용 능력치 | Strength, Charisma, Wit, Magic은 표시 조건이 확인되기 전까지 현재 빌드용 계획 메모입니다 |
| 추천 기준점 | 가능할 때 Angelica, Brunhilda, Dullahan, Gwendan을 비교 대상으로 사용 |
| 핵심 충돌 | 세력 약속, 로맨스 우선순위, 하인 선택, 루트별 기사 접근 |
| 주요 위험 | 한 번 성공한 플레이를 보편적인 캠페인 루트의 증거로 취급하는 것 |

## 단계 / 루트 적합도

1. Act 0이 끝나기 전에 캠페인 장부를 시작하세요. 명단, 세력 상태, 탑 접근, 알려진 퀘스트, 해결되지 않은 루트 단서를 기록합니다.
2. 안정적인 퀘스트 이름, 표시 요구 조건, 반복 가능한 결과가 있는 마일스톤은 하위 페이지로 분리합니다.
3. 퀘스트 인터페이스가 정확한 요구 조건을 보여주지 않는 한 넓은 능력치 조언은 임시로 표시합니다.
4. 세력, 로맨스, 하인, 기사 영입 선택이 서로 경쟁하기 시작하는 시점을 추적합니다.
5. 중요한 결정 주변에서 되감기 테스트를 사용해 가벼운 결과와 실제 루트 잠금을 구분합니다.
6. 각 액트 전환마다 충성도, 부상, 세력 평판, 재정 압박, 부속 시설 접근, 영입 기사 같은 이어지는 플래그를 요약합니다.

## 현재 빌드 확인 사항

| 확인할 주장 | 검증 메모 |
|---|---|
| 액트 경계 | Act 0, Act 1, 중반, 후반 루트 상태가 실제로 어디서 바뀌는지 확인 |
| 하드 게이트 | 현재 빌드 값은 표시 요구 문구와 스크린샷으로 기록 |
| 영입 충돌 | 기사 선택이 이후 영입을 막는지, 지연시키는지, 아니면 대사만 바꾸는지 테스트 |
| 세력 잠금 | 균형, 우호, 적대 세력 상태를 비교한 뒤 루트 폐쇄를 주장 |
| 엔딩 로직 | 반복 캠페인에서 확인되기 전까지 엔딩 조건과 추측을 분리 |

## FAQ

### 최고의 전체 캠페인 루트가 하나 있나요?

아직 아닙니다. 가장 안전한 루트는 하나의 최적 경로를 가정하는 대신 분기를 비교할 수 있게 잘 기록된 캠페인 장부입니다.

### 어떤 선택을 먼저 기록해야 하나요?

세력 변화, 영입 결정, 로맨스 신호, 하인 또는 부속 시설 변화, 충성도나 향후 이용 가능성에 영향을 주는 퀘스트 실패를 먼저 기록하세요.

### 계획용 능력치를 루팅에 써도 되나요?

계획 힌트로만 사용하세요. 정확한 추천은 표시 요구 조건이나 반복된 게임 내 결과에서 나와야 합니다.

### 캠페인 주장은 언제 게시해도 안전한가요?

같은 결정이 반복 플레이에서 같은 효과를 내거나 공식 텍스트로 확인된 뒤에만 단정적으로 게시하세요.
