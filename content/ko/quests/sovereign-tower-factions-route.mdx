## 빠른 답변

세력 루트에서는 Merchants, Mystics, Scholars, Nobles, the People, Treasury의 승인도를 바꾸는 모든 결정을 계속 기록하세요. 중요한 질문은 어느 세력이 항상 최고인지가 아니라, 현재 루트에서 어떤 약속이 안정적인 접근을 만들어 주는지입니다.

## 세력 개요

| 루트 포인트 | 작업 계획 |
|---|---|
| 주요 목표 | 어떤 세력 상태가 퀘스트와 알현을 열고, 바꾸고, 닫는지 파악 |
| 계획용 능력치 | Charisma, Wit, Strength는 협상, 계략, 집행을 위한 현재 빌드용 계획 메모 |
| 추천 기준점 | 표시 적합성이 맞을 때 Gwendan, Brunhilda, Dullahan을 비교 대상으로 사용 |
| 좋은 특성 | 궁정형, 루트 지식, 전투 준비, 안정적인 충성도 |
| 주요 위험 | 소외된 세력이 무엇을 통제하는지 알기 전에 한 집단을 과도하게 편드는 것 |

## 단계 / 루트 적합도

1. 주요 퀘스트나 알현 결정 전에 세력 장부를 만듭니다.
2. 시작 상태, 결정 문구, 배정 기사, 결과, 게임이 보여주는 승인도 변화를 기록합니다.
3. 즉시 표시되는 승인도 변화와 반란 압박 또는 영입 차단 같은 지연 결과를 분리합니다.
4. 세력 결과를 [Alliances Route](/quests/sovereign-tower-alliances-route), [Rebellion](/quests/sovereign-tower-rebellion), 전체 캠페인 루트와 비교합니다.
5. 극단적인 정렬 경로를 테스트하기 전에 균형 상태 저장을 통제 지점으로 사용합니다.
6. 이름이 있는 세력 퀘스트는 요구 조건과 보상이 안정되면 별도 페이지로 승격합니다.

## 현재 빌드 확인 사항

| 확인할 주장 | 검증 메모 |
|---|---|
| 추적 그룹 수 | 현재 빌드가 Treasury를 완전한 세력형 축으로 다루는지, 병렬 자원으로 다루는지 확인 |
| 승인도 임계값 | 보이는 경우에만 넓은 라벨을 정확한 게임 내 문구로 교체 |
| 루트 잠금 | 낮은 평판이 선택지를 막는지, 대사를 바꾸는지, 보상만 바꾸는지 테스트 |
| 반란 압박 | 균형 세력 상태와 적대 세력 상태에서 같은 퀘스트를 비교 |
| 기사 충성도 | 세력 편애가 충성도, 배신 위험, 영입에 영향을 주는지 확인 |

## FAQ

### 모든 세력을 만족시킬 수 있나요?

플레이의 일부 구간에서는 가능할 수 있지만, 승인도 변화와 충돌이 처음부터 끝까지 확인되기 전까지 완벽한 루트라고 주장하면 안 됩니다.

### 어느 세력을 우선해야 하나요?

현재 루트 목표와 연결된 세력을 우선하고, 다른 곳에서는 알 수 없는 잠금을 피할 만큼 중립 상태를 유지하세요.

### 세력 잠금은 확인되었나요?

일부 루트 효과는 가능성이 높지만, 반복 테스트에서 같은 선택지가 사라지는 것이 보이기 전까지 잠금은 확인 대기 상태로 다루세요.

### 세력을 테스트하는 가장 좋은 방법은 무엇인가요?

균형 저장을 통제 지점으로 유지한 뒤, 한 번에 하나의 큰 정렬 변화만 테스트하고 즉시 바뀌는 것과 나중에 바뀌는 것을 따로 기록하세요.
