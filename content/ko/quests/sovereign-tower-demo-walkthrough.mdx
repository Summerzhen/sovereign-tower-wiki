## 빠른 답변

Sovereign Tower 데모에서는 최적화하기 전에 신중한 기준 루트를 한 번 플레이하세요. 보이는 모든 퀘스트 요구 조건을 기록하고, 튜토리얼 임무에는 안전한 초반 기사를 배정하며, 확정된 문구와 아직 테스트해야 할 가정은 따로 적어 두세요.

## 데모 루트 개요

| 루트 지점 | 할 일 |
|---|---|
| 범위 | 데모를 알현, 배정, 친밀도, 되감기 동작을 배우는 확인용 플레이로 다루기 |
| 능력치 메모 | UI가 정확한 값을 확인해 줄 때까지 민첩, 매력, 행운은 계획용 단서로만 사용하기 |
| 더 안전한 배정 | 보이는 요구 조건에 맞는다면 Angelica나 Gwendan 같은 신뢰도 높은 초반 기사를 먼저 사용하기 |
| 주요 위험 | 데모에서 검증하지 않은 가정을 이후 루트 페이지로 가져가는 것 |
| 최선의 결과 | 확인된 퀘스트 이름, 요구 조건, 루트 플래그, 미해결 단서를 짧게 정리한 목록 |

## 단계별 진행

1. 퀘스트 이름, 알현 순서, 사용 가능한 기사, 튜토리얼 경고를 적을 새 메모 페이지로 데모를 시작하세요.
2. 퀘스트가 나타나면 기사를 고르기 전에 보이는 요구 조건을 복사하세요.
3. 가장 쉬워 보이는 퀘스트가 안전하다고 가정하지 말고, 요구 조건을 현재 기사 명단과 비교하세요.
4. 저위험 튜토리얼 배정을 이용해 성공, 실패, 충성도, 특성 문구가 어떻게 표시되는지 확인하세요.
5. 하인, 세력, 숨겨진 특성, 이후 지역을 언급하는 불명확한 루트 플래그는 모두 미확정으로 표시하세요.
6. 데모를 끝낸 뒤 어떤 메모가 퀘스트 기록으로 만들 만큼 확실한지, 어떤 메모가 2회차 확인을 요구하는지 검토하세요.

## 확인할 사항

| 확인할 주장 | 검증 메모 |
|---|---|
| 데모 능력치 조건 | 임시 계획용 능력치를 현재 빌드에 표시되는 정확한 값으로 교체하기 |
| 이월 요소 | 데모 선택이 이후 저장, 해금, 루트 이용 가능 여부에 영향을 주는지 확인하기 |
| 튜토리얼 실패 | 실패가 단순히 시스템을 가르치는지, 이후 퀘스트 상태를 바꾸는지 테스트하기 |
| 기사 선호 | 기사가 데모 배정을 좋아하는지, 싫어하는지, 고유 반응을 보이는지 기록하기 |
| 미해결 이름 | 데모 안에서 완료되지 않는 모든 이름 있는 퀘스트, 하인, 세력, 루트 단서를 추적하기 |

## FAQ

### 이 페이지는 데모 전체 해답인가요?

신뢰할 수 있는 메모를 만들기 위한 신중한 루트 페이지입니다. 데모 전용 퀘스트의 정확한 해답은 현재 데모 빌드를 다시 플레이하고 보이는 요구 조건 문구를 확인한 뒤 추가해야 합니다.

### 첫 데모 플레이를 바로 최적화해야 하나요?

바로 그럴 필요는 없습니다. 기준 플레이는 게임이 무엇을 설명하는지, 어떤 선택을 되돌릴 수 있는지, 어떤 요구 조건을 놓치기 쉬운지 보여 주기 때문에 더 유용합니다.

### 나열된 능력치는 확정인가요?

아닙니다. 데모 UI가 정확한 판정을 확인해 줄 때까지 초반 민첩, 매력, 행운 메모는 보수적인 계획용 임시값으로 다루세요.
