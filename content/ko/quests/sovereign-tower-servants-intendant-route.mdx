## 빠른 답변

하인과 인텐던트 루트는 탑 내부 관리를 추적하는 데 사용하세요. 하인 이름, 인텐던트 대화, 부속 시설 언급, 자원 효과, 퀘스트 접근, 충성도, 향후 위험을 바꾸는 행정 선택을 기록합니다.

## 루트 개요

| 루트 지점 | 작업 계획 |
|---|---|
| 주요 목표 | 탑 운영 선택과 그것이 하인, 부속 시설, 자원에 주는 영향을 지도화한다 |
| 계획용 스탯 | 재치, 카리스마, 운은 행정, 설득, 불확실성을 위한 임시값이다 |
| 추천 기준점 | Gwendan, Angelica, Dullahan은 사용 가능할 때 비교 기준으로 유용하다 |
| 최적 특성 | 문제 해결, 외교, 루트 지식, 신중한 판단 |
| 주요 위험 | 테스트 전에 분위기용 하인 대화를 확정된 기계적 해금으로 취급하는 것 |

## 단계 / 루트 적합성

1. 각 하인, 인텐던트 장면, 부속 시설 언급, 탑 운영 문제가 나타날 때 기록합니다.
2. 선택하기 전에 현재 자원, 세력 상태, 명단의 부상, 이용 가능한 부속 시설을 적습니다.
3. 표시 요구사항이나 장면 논리에 따라 기사를 배정한 뒤, 특성이 신뢰, 규율, 회복, 접근을 바꾸는지 기록합니다.
4. 행정 분위기 대사와 새 직책, 자원 변화, 옵션 해금 같은 확인된 시스템 변화를 분리합니다.
5. 불분명한 선택 주변에서 되감기해 다른 기사나 판결이 같은 하인 결과를 바꾸는지 테스트합니다.
6. 하인 또는 인텐던트 이벤트의 분기가 안정되면 별도 퀘스트 기록으로 나눕니다.

## 확인할 사항

| 확인할 주장 | 검증 메모 |
|---|---|
| 하인 이름 | 개별 페이지를 만들기 전에 게임 내 텍스트에서 정확한 이름과 역할을 확인 |
| 인텐던트 기능 | 인텐던트가 자원, 루트 접근, 탑 질서, 또는 대화만 바꾸는지 추적 |
| 부속 시설 지원 | 선택이 대장간, 연금술, 정원, 거처 같은 시스템을 해금, 개선, 언급하는지 확인 |
| 기사 영향 | 특성이 하인 신뢰나 행정 결과에 영향을 주는지 테스트 |
| 장기 비용 | 지연된 충성도, 세력, 자원, 루트 결과를 따로 기록 |

## FAQ

### 인텐던트 루트는 전투 루트인가요?

아니요. 특정 이벤트가 전투나 퀘스트 배정 요구사항을 보여주기 전까지는 탑 관리 루트로 다루세요.

### 하인 선택이 부속 시설을 해금할 수 있나요?

그럴 수 있지만, 이 페이지는 선택이 안정적으로 시스템 변화를 만들 때까지 해금 표현을 신중하게 유지해야 합니다.

### 하인 이벤트에는 어떤 스탯이 중요하나요?

재치와 카리스마는 유용한 계획 범주이고, 운은 불확실한 결과에 사용됩니다. 정확한 판정은 여전히 표시 확인이 필요합니다.

### 하인 이벤트는 언제 자체 페이지가 필요하나요?

이벤트에 안정적인 이름, 명확한 요구사항, 알려진 결과, 반복 가능한 루트 결과가 있을 때 전용 페이지를 만드세요.
