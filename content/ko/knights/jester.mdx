## 빠른 답변

Jester는 예측하기 어렵고 궁정에 맞닿은 기사 후보로 다루는 것이 좋습니다. Wit, Luck, 공개 장면, 이상한 debrief가 중요할 수 있는 퀘스트에서 테스트하되, 그 상호작용이 검증되기 전에는 Jester가 특수 결과를 강제로 만들 수 있다고 가정하지 마세요.

## 프로필 개요

| 항목 | 현재 작업 가정 |
|---|---|
| 역할 | 특수 영입 후보 |
| 최적 용도 | 이상한 일, 공개 장면, 예상 밖 결과 테스트 |
| 테스트할 가능 강점 | Wit, Luck, 사회적 속임수 |
| 영입 상태 | 미검증; 명명된 영입 대상, 원형, 이벤트 라벨일 수 있음 |
| 주요 위험 | 광대 원형을 근거 없는 메커니즘으로 바꾸는 것 |

## 최적 퀘스트 적합도

초기 테스트에 가장 강한 후보는 [Goose Quest](/quests/sovereign-tower-goose-quest), [Groveshire](/quests/sovereign-tower-groveshire), [Rebellion](/quests/sovereign-tower-rebellion)입니다. Goose Quest는 이상한 생물 또는 공개 장면 결과가 Jester의 색채를 드러낼 수 있어 유용합니다. Groveshire와 Rebellion은 재치, 도발, 사회적 교란이 루트를 바꾸는지 확인하기 좋습니다.

Jester는 비교용 선택지로 쓰세요. 같은 퀘스트를 일반적인 고능력치 기사로 실행한 뒤 Jester를 테스트하고 debrief 문구, affinity 변화, 숨은 특성 공개를 비교하세요.

## 확인할 특성

| 특성 질문 | 확인 방법 |
|---|---|
| 예측 불가 | 일반 성공, 실패, 예상 능력치 논리와 다른 debrief 텍스트를 찾기 |
| 궁정 지향 | Jester가 여론, 귀족, Round Table 사기에 영향을 주는지 테스트 |
| 속임수 후보 | 조사, 장난, 소문, 혼란 테마 퀘스트가 나오면 사용 |
| 숨은 혼돈 판정 | 예상 밖 결과 뒤 되감고 Jester가 이를 재현할 수 있는지 확인 |

## FAQ

### Jester는 특정 캐릭터인가요, 일반 용어인가요?

아직 검증이 필요합니다. 기존 설명은 "jester"를 괴짜 기사들을 가리키는 넓은 라벨로 쓰지만, 데이터베이스는 이를 특수 영입 또는 이벤트 라벨 후보로 추적합니다.

### Jester가 예상 밖 결과를 만들 수 있나요?

아직 그렇게 가정하지 마세요. Jester는 특이한 결과를 테스트하기 좋은 후보지만, 가이드는 반복 가능한 결과가 나온 뒤에만 특수 효과를 주장해야 합니다.

### Jester가 피해야 할 퀘스트는 무엇인가요?

실제 능력치와 특성이 확인되기 전에는 명확한 Strength 또는 Magic 요구 조건이 있는 퀘스트에서 Jester를 유일한 답으로 삼지 마세요.

### Jester에게 가장 유용한 증거는 무엇인가요?

프로필, 영입 텍스트, 퀘스트 배치 화면, 결과 debrief, 숨은 특성 공개 스크린샷이 있으면 이 원형 가이드를 정확한 기사 페이지로 바꿀 수 있습니다.
