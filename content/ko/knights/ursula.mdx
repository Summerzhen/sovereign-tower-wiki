## 빠른 답변

Ursula는 외교의 첫 선택이 되어서는 안 됩니다. 정확한 영입 상태, 스탯, 루트 연결이 검증되는 동안 전투, 마법 압박, 명확한 목표 퀘스트용 직접 특화 기사로 다루세요.

## 프로필 개요

| 항목 | 현재 작업 해석 |
|---|---|
| 역할 | 영입 가능한 기사 후보 |
| 최적 용도 | 비외교 임무, 전투 압박, 마법 압박, 명확한 목표 |
| 테스트할 가능성 높은 강점 | 힘과 마법, 카리스마는 강한 주의 신호 |
| 영입 상태 | 게임 내 증거가 확인하기 전까지 표준, 초반, 루트 전용 여부 미검증 |
| 주요 위험 | 확인된 보완 특성, 아이템, 루트 조건 없이 사회 퀘스트에 보내는 것 |

## 단계 / 최적 활용

현재 데이터는 Ursula를 [드래곤 나이트](/quests/sovereign-tower-dragon-knight), [Gavault](/quests/sovereign-tower-gavault), [야수 사냥](/quests/sovereign-tower-beast-hunt)과 연결합니다. 따라서 이용 가능성이 확인되면 직접적이고 위험하거나 기묘한 임무에 좋은 후보입니다.

Ursula를 통제 비교 대상으로 사용하세요. 외교 임무에는 높은 카리스마의 기사를 보낸 뒤, 게임이 특별한 반전을 암시하지 않는 한 Ursula는 그곳에 쓰지 않습니다. 전투 또는 마법 코드의 퀘스트에서는 확정 조언을 쓰기 전에 그녀의 결과 문구를 다른 특화 기사와 비교하세요.

## 확인할 사항

| 특성 질문 | 확인 방법 |
|---|---|
| 영입 시점 | Ursula가 초반 명단, 표준 영입, 루트 전용인지 확인 |
| 카리스마 경고 | 안전할 때만 테스트하고, 사회 실패 문구가 약점을 직접 언급하는지 기록 |
| 특화 가치 | 드래곤 나이트, Gavault, 야수 사냥 결과를 비슷한 기사들과 비교 |
| 숨은 루트 연결 | Ursula가 배신, 충성도, Act 2식 분기 보고에 등장하는지 추적 |
| 정확한 스탯 | 임시 힘, 마법, 카리스마를 표시되는 게임 내 값으로 교체 |

## FAQ

### Ursula는 나쁜가요?

아니요. 주의점은 외교에 한정됩니다. 임무가 힘, 마법, 결단, 직접 행동을 요구한다면 가치 있을 수 있습니다.

### Ursula가 카리스마 퀘스트를 맡아야 하나요?

검증된 특성, 아이템, 루트 조건이 다르게 말하기 전까지 피하세요. 기존 문서는 그녀를 매력 담당으로 쓰지 말라고 경고합니다.

### Ursula는 배신 루트와 연결되어 있나요?

추적할 만한 루트 보고는 있지만, 이 페이지는 통제된 증거 없이 배신 세부 사항을 확정처럼 제시해서는 안 됩니다.

### Ursula 가이드를 완성하려면 무엇이 필요한가요?

확인된 영입 시점, 정확한 스탯, 알려진 선호, 숨은 특성 증거, 특화 및 사회 퀘스트 양쪽의 검증된 결과가 필요합니다.
