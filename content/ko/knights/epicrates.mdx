## 빠른 답변

Epicrates는 아직 확정된 기사 클래스, 희귀도 단계, 보장 영입 대상으로 다루면 안 됩니다. 이 페이지는 Epicrates가 캐릭터인지, 특수 조우인지, 루트 라벨인지, 더 깔끔한 증거가 필요한 커뮤니티 약칭인지 테스트하는 심화 가이드로 사용하세요.

## 프로필 개요

| 항목 | 현재 작업 가정 |
|---|---|
| 역할 | 특수 영입 후보 |
| 최적 용도 | 실험적 루트와 낮은 위험의 정보 수집 루프 |
| 테스트할 가능 강점 | Luck, Charisma, Magic, 특이 결과 판정 |
| 영입 상태 | 미검증; 정확한 조우 규칙은 보류 |
| 주요 위험 | 희귀하거나 커뮤니티에서 제보된 데이터를 과장하는 것 |

## 최적 퀘스트 적합도

현재 데이터베이스는 Epicrates를 [Gavault](/quests/sovereign-tower-gavault), [Goose Quest](/quests/sovereign-tower-goose-quest), [Hammer Lost, Yet Again](/quests/sovereign-tower-hammer-lost-yet-again)에 연결합니다. 따라서 특이한 결과, 부드러운 외교, 운이 중요할 수 있는 이상한 임무에 좋은 테스트 후보입니다.

이 연결은 보장 추천이 아니라 테스트 루트로 다루세요. Epicrates가 한 run에서 등장하면 먼저 낮은 위험의 퀘스트 하나에 배치하고 결과 텍스트를 기록한 뒤, 특수 메커니즘을 주장하기 전에 되감거나 다른 기사와 비교하세요.

## 확인할 특성

| 특성 질문 | 확인 방법 |
|---|---|
| 희귀 조우 후보 | 첫 등장 전 주기, 알현 선택, 세력 상태, 탑 업그레이드를 기록 |
| 커뮤니티 제보 후보 | 반복 가능한 증거와 단일 스크린샷 또는 검색 기반 추측을 분리 |
| 데이터 보류 | Epicrates에게 초상화, Round Table 슬롯, 퀘스트 배치 가능 여부, debrief 텍스트가 있는지 기록 |
| 숨은 희귀 조건 | 같은 조건의 루트가 Epicrates를 두 번 생성하는지 테스트 |

## FAQ

### Epicrates는 확실히 기사인가요?

아직 아닙니다. 공식 텍스트나 반복 가능한 플레이 증거로 역할이 확인될 때까지 Epicrates는 특수 영입 후보 또는 캐릭터 데이터 항목이라고 쓰는 것이 가장 안전합니다.

### 왜 Epicrates를 이상한 퀘스트와 연결하나요?

현재 프로필이 희귀하고 예상 밖인 상호작용을 테스트하는 데 맞춰져 있기 때문입니다. 특이한 결과가 있는 퀘스트는 단순 능력치 확인보다 좋은 증거 수집 도구입니다.

### Epicrates의 정확한 영입 절차를 공개해도 되나요?

같은 절차가 반복 run에서 작동하기 전까지는 안 됩니다. 제보를 지침으로 바꾸기 전에 루트, 선택, 주기, 세력 값, 탑 부속 시설을 기록하세요.

### 이 페이지가 완성되려면 무엇이 필요하나요?

확인된 역할, 정확한 영입 맥락, 검증된 능력치 라인, 알려진 선호, Epicrates가 실제로 무엇을 잘하는지 보여주는 퀘스트 결과 최소 두 개가 필요합니다.
