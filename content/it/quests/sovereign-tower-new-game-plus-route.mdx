## Risposta Rapida

Prima di usare qualunque consiglio sul percorso New Game Plus, conferma se New Game Plus esiste nella build attuale che stai giocando. Se esiste, documenta trasferimento, requisiti missione alterati, cambiamenti alla rosa e conoscenza nascosta separatamente dal percorso della campagna base.

## Panoramica New Game Plus

| Punto del Percorso | Cosa Verificare |
|---|---|
| Stato della modalità | Conferma che New Game Plus sia presente e accessibile nella build attuale |
| Trasferimento | Controlla conoscenza, rosa, tratti, sblocchi, risorse e flag di percorso |
| Note statistiche | Tratta Fortuna, Acume e Magia solo come categorie provvisorie di pianificazione |
| Percorso di confronto | Collega ogni missione modificata alla sua versione della campagna base |
| Rischio principale | Pubblicare comportamento dipendente dalla build come se fosse universale |

## Passo per Passo

1. Completa o carica lo stato finale richiesto, poi conferma se viene davvero offerta un'opzione New Game Plus.
2. Avvia il nuovo percorso e registra esattamente cosa viene trasferito prima di accettare qualunque missione.
3. Confronta l'ordine delle udienze iniziali con le note di Atto 0 e primi cicli.
4. Controlla se tratti, requisiti o indizi di percorso prima nascosti sono ora visibili.
5. Per ogni missione modificata, registra versione base, versione NG+ e conseguenza pratica.
6. Mantieni questa pagina prudente finché più run non confermano gli stessi sblocchi e differenze di percorso.

## FAQ

### New Game Plus è confermato?

Questa pagina va trattata come percorso di verifica finché la build attuale non conferma la modalità e il suo comportamento di sblocco.

### Cosa dovrei confrontare per prima cosa?

Confronta stato iniziale, cavalieri disponibili, requisiti visibili e flag di percorso. Queste differenze contano più dell'ottimizzazione delle ricompense nel primo test NG+.

### New Game Plus può cambiare il reclutamento?

Potrebbe, ma non darlo per certo. Traccia i percorsi di reclutamento, inclusi i flag legati a Brunhilda, rispetto a una base della campagna normale prima di fare affermazioni solide.
